Three DOF Robot (Kinematic Redundancy)

This tool visualizes a 3-DOF planar robot and its reachable workspace. You can adjust the joint angles and link lengths to see how the robot's configuration changes in both task space and configuration space.

Remember that the nullspace solution of a kinematic redundancy is not guarantee to be continuous. Therefore, the nullspace motion may not be smooth or predictable. You may see a jump in solution while the plot line is continuous. This is because of the line plot rendering, which connects the points with a straight line.

Use the controls below to explore the robot.

2D Taskspace

The shaded annulus is the reachable position workspace.

3D Configuration Space

Each curve is one position-only IK branch.
